# 🎓 Srushti's Student Hub

A responsive student dashboard built with **HTML, CSS, and JavaScript** to organize academic progress, projects, skills, and certificates in one place.

## 🌐 Live Demo

**[Visit Srushti's Student Hub](https://srushti-student-hub.vercel.app)**

## ✨ Features

- 📊 **Dashboard** — Overview of courses, projects, and skills.
- 📚 **Courses** — Organize and explore course information.
- 💻 **Projects** — Showcase projects with technologies and completion status.
- ⚡ **Skills** — Display technologies and learning progress.
- 🏅 **Certificate Tracker** — Add, search, and manage earned certificates.
- 👤 **Student Profile** — View student profile information.
- 🌙 **Dark/Light Mode** — Switch between display themes.
- 📱 **Responsive Design** — Designed for desktop, tablet, and mobile screens.

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Git and GitHub
- Vercel

## 🚀 Run Locally

1. Clone this repository:

   ```bash
   git clone https://github.com/srushtichaudhari70-stack/Student-Hub-Dashboard.git
   ```

2. Open the project folder.
3. Open `index.html` in your browser.

No build tools are required for the basic HTML, CSS, and JavaScript version.

## 💾 Data Storage

The certificate tracker uses browser local storage if enabled in the current implementation. Data stored locally may not sync across different browsers or devices.
